CSS作业答案

第一部分：修复卡片 CSS

第一处：给 li 添加 overflow: hidden，裁切放大后溢出的图片。

.box li {
  width: 300px;
  overflow: hidden;
  position: relative;
}

第二处：把 transition 写在普通选择器上，移入和移出都会有动画。

.box img { transition: all .6s; }
.box li:hover img { transform: scale(1.2); }

第三处：给 li 添加 position: relative，让绝对定位的文字条以卡片为参照物。

第二部分：补全答案

2.1 语义标签：页面顶部头部区域是 <header>；导航条是 <nav>；页面唯一主要内容区是 <main>；侧边栏附属内容是 <aside>；页面底部版权页脚是 <footer>。

2.2 卡片动画：防止图片溢出使用 overflow: hidden；子绝父相使用 position: relative；图片选择器是 .box li img 和 .box li:hover img；奇数卡片选择器是 li:nth-child(odd):hover .txt。

2.3 flex 两栏布局：父容器使用 display: flex，两栏间距使用 gap: 8px。

第三部分：简答

1. overflow:hidden 的两个作用：隐藏超出盒子范围的内容，裁切缩放后的图片；同时可以清除浮动，解决父元素高度塌陷。

2. scale(1.2) 会不会挤压旁边卡片？不会。transform 只改变视觉上的渲染效果，不会改变元素在文档流中的实际占位。

3. transition 写在 hover 和普通选择器上的区别：写在普通选择器上，移入和移出都有过渡动画；写在 :hover 上，只有移入有动画，移出会瞬间恢复。

4. bug 记录：文字定位跑到浏览器底部，是因为父级 li 忘记设置 position: relative，子级 absolute 以页面作为定位基准；给 li 加上相对定位即可。

5. 第三部分画图：手绘父级 relative 和子级 absolute 盒子，再截图粘贴到作业中。

第四部分：回到顶部（选做）

使用 href="#top" 的锚点返回页面顶部，不需要 JavaScript。按钮使用 position: fixed 固定在左下角，并通过 opacity 和 transform 设置悬浮效果。
