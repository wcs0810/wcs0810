# 网页抓小球训练游戏 v2（Aim Lab 风格）— 需求规格文档

> 版本 v2.0 · 基于 v1.0 全面升级 · 参考 Steam Aim Lab 核心设计逻辑
> 变更摘要：严格命中判定 + 偏差/反应时间统计 · 限时寿命小球 · 难度梯度 · 实时数据面板 · Web Audio 合成音效 · 粒子爆裂反馈

---

## 1. 项目概述

### 1.1 升级目标
将 v1 的简单"抓球得分"升级为接近 Aim Lab 专业射击训练体验的网页训练游戏，聚焦精准点击、反应速度、稳定性三大核心训练维度。

### 1.2 核心设计原则（源自 Aim Lab）
1. **精准可量化**：每一次点击都记录命中/未命中、反应时间、偏差距离
2. **科学递进**：难度随时间自动提升，训练强度可控
3. **即时反馈**：视觉（粒子/命中环）+ 听觉（合成音效）双通道反馈
4. **数据驱动**：实时展示命中率、反应时间、平均偏差等关键指标

## 2. 功能需求明细

### 2.1 游戏状态机（不变，沿用 v1）

```
[idle] → [countdown 5→1→GO] → [playing 60s] → [ended]
   ↑                                 │
   └───────── 再来一次 ──────────────┘
```

### 2.2 核心玩法规则

| 规则项 | v1 值 | v2 值 | 变更说明 |
|--------|-------|-------|----------|
| 开场倒计时 | 5s | 5s | 不变 |
| 游戏总时长 | 60s | 60s | 不变 |
| 命中得分 | +1 | +1 | 不变 |
| 未命中扣分 | -1（最低0） | -1（最低0） | 不变 |
| 命中判定 | 点中 DOM 即命中 | **严格像素判定** | 点击点到球心距离 ≤ 球半径才算命中 |
| 小球寿命 | 无限 | **限时寿命** | 超时未命中自动消失并换位置 |
| 同屏小球上限 | 3 | 3~5（随难度递增） | 难度越高目标越多 |
| 小球尺寸 | 固定 60px | **随难度递减** | 32~60px |

### 2.3 难度梯度系统

每 10 秒自动升级一级，60 秒游戏共 6 级：

| 等级 | 时间区间 | 小球直径 | 寿命 | 同屏上限 |
|------|----------|----------|------|----------|
| L1 | 0–10s | 60px | 2000ms | 3 |
| L2 | 10–20s | 54px | 1700ms | 3 |
| L3 | 20–30s | 48px | 1400ms | 4 |
| L4 | 30–40s | 42px | 1100ms | 4 |
| L5 | 40–50s | 36px | 900ms | 5 |
| L6 | 50–60s | 32px | 750ms | 5 |

- 难度升级时屏幕中央弹出"LEVEL UP → Ln"提示（800ms 后消失）
- 小球尺寸变化**只对新生成的小球生效**，已存在的小球保持原尺寸

### 2.4 小球生成逻辑

- **生成触发**：① 点中旧球 → 立即生成新球；② 小球寿命超时 → 自动消失并生成新球
- **位置**：v1 的随机边界 + 间距检测逻辑保持
- **生命周期**：每个小球有 `spawnTime` 时间戳，`setTimeout(lifespan)` 后自动移除并补位
- **点中处理**：清除该球的寿命定时器，播放消失动画后移除 DOM

### 2.5 点击判定与数据采集

#### 命中判定（严格像素级）
```
点击点 (clickX, clickY)，球心 (ballCX, ballCY)，球半径 r
distance = √((clickX - ballCX)² + (clickY - ballCY)²)
命中条件：distance ≤ r
```
- 即使点击点在小球 DOM 元素的方形区域内但超出圆形边界，也算未命中
- 命中时记录 `deviation = distance`（像素，越小越精准）

#### 反应时间
```
reactionTime = clickTimestamp - ball.spawnTime （毫秒）
```
- 记录每次命中的反应时间，计算平均值展示

#### 统计指标
| 指标 | 公式 | 说明 |
|------|------|------|
| 命中率 | `hits / totalClicks × 100%` | totalClicks 含命中 + 未命中 |
| 平均反应时间 | `sum(reactionTime) / hits` | 仅命中的球参与计算，单位 ms |
| 平均偏差 | `sum(deviation) / hits` | 仅命中的球参与计算，单位 px |
| 击杀数 / 总点击 | `hits / totalClicks` | 如 120/145 |

### 2.6 实时数据统计面板

**位置**：顶部分数栏扩展为信息面板（高度 64px 不变），从左到右排列：
```
[⏱ 60s]  [分数: 0]  [命中率: --%]  [反应: --ms]  [偏差: --px]  [命中: 0/0]  [Lv.1]
```

**更新时机**：
- 每次点击（命中或未命中）后立即刷新所有指标
- 难度升级时更新 Lv. 显示

**样式**：
- 指标用等宽字体 `font-family: monospace`，数字跳动时不抖动布局
- 命中率 ≥ 80% 绿色，60-80% 黄色，< 60% 红色
- 反应时间 ≤ 300ms 绿色，300-500ms 黄色，> 500ms 红色
- 平均偏差 ≤ 10px 绿色，10-20px 黄色，> 20px 红色

### 2.7 视觉反馈升级

#### 命中反馈
1. **爆裂粒子**：从球心向外放射 8-12 个小圆点（颜色同小球），扩散 40-60px 后淡出，300ms
2. **命中环**：从点击点扩散的白色圆环（scale 1→2.5，opacity 1→0），250ms
3. **飘字**："+1" 绿色，附带反应时间（如 "+1 · 280ms"）
4. **小球消失**：scale 1.2 + opacity 0，200ms

#### 未命中反馈
1. **X 标记**：在点击位置显示红色 "✕" 标记，400ms 淡出
2. **飘字**："-1" 红色
3. **分数栏红闪**：沿用 v1

#### 小球寿命警告
- 寿命剩余 ≤ 30% 时，小球开始闪烁（opacity 1↔0.4，每 100ms 切换），提示即将消失

#### 难度升级提示
- 屏幕中央弹出半透明 "LEVEL UP → Ln"，800ms 淡入淡出

### 2.8 音效系统（Web Audio API 合成，零外部文件）

| 事件 | 音效描述 | 参数 |
|------|----------|------|
| 命中 | 高频短促"叮" | Oscillator sine, 880Hz, 0.08s, gain 0.15 指数衰减 |
| 未命中 | 低频"噗" | Oscillator square, 180Hz, 0.12s, gain 0.1 |
| 难度升级 | 上行双音 | 440Hz → 660Hz, 各 0.1s |
| 游戏结束 | 下行三音 | 660Hz → 440Hz → 330Hz, 各 0.15s |

- 懒加载：第一次用户交互时创建 AudioContext（浏览器策略要求用户手势后才能播放）
- 音效可静音：分数栏右侧加 🔊/🔇 切换按钮

### 2.9 游戏结束展示升级

结束遮罩增加统计详情：
```
游戏结束
本次得分：X 分

命中率：85%   反应时间：320ms
平均偏差：8.5px   命中：120/145

[再来一次]
```

## 4. 技术实现要求（增量）

### 4.1 数据结构变更

```js
// 小球对象
const ball = {
  el: DOMElement,
  spawnTime: timestamp,   // 用于反应时间计算
  lifespan: number,       // ms
  size: number,           // px
  cx: number, cy: number, // 球心坐标（相对于游戏区域）
  lifeTimer: timeoutID
};

// 统计状态
const stats = {
  hits: 0,
  totalClicks: 0,
  reactionTimes: [],    // 每次命中的反应时间数组
  deviations: []        // 每次命中的偏差数组
};
```

### 4.2 性能要求（增量）

| 项 | 要求 |
|----|------|
| 小球定位 | 用 `transform: translate(x, y)` 而非 `left/top`，启用 GPU 合成 |
| 粒子动画 | 纯 CSS `@keyframes`，不使用 JS requestAnimationFrame 驱动粒子 |
| 音效 | AudioContext 单例复用，不为每个音效创建新 context |
| 小球寿命 | 用 `setTimeout` 而非 `setInterval`，避免漂移 |

### 4.3 不变的约束
- 零第三方依赖，纯原生 HTML/CSS/JS
- 单文件结构（index.html / css/style.css / js/main.js）
- 响应式断点保持 v1
