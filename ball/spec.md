# 网页抓小球小游戏 — 需求规格文档（spec.md）

> 版本 v1.0 · 高级网页设计 课堂作业 · 2026-2027-1

---

## 1. 项目概述

### 1.1 项目背景
一个基于原生 HTML+CSS3+JavaScript 的前端网页小游戏，玩家在限定时间内尽可能多地点击页面上随机出现的蓝色圆形小球获得分数。用于课堂演示前端基础交互、动画与 DOM 操作。

### 1.2 项目目标
- 提供简单有趣的 60 秒限时抓球体验
- 零第三方依赖，纯原生实现
- 兼容主流现代浏览器（Chrome / Edge / Firefox / Safari 最新两版）

### 1.3 术语定义
| 术语 | 说明 |
|------|------|
| 小球（Ball） | 页面上随机位置出现的可点击蓝色圆形元素 |
| 分数栏 | 位于页面顶部，实时展示当前得分与剩余时间的 UI 区域 |
| 开场倒计时 | 点击开始按钮后，游戏正式开始前的 5 秒倒计时动画 |
| 游戏时间 | 正式开始后 60 秒倒计时，归零即停止 |

## 2. 功能需求明细

### 2.1 游戏状态机

```
[初始] ──点击"开始游戏"──▶ [开场倒计时 5→1→GO] ──▶ [游戏进行中] ──60秒归零──▶ [游戏结束]
                          (可按取消中断)                                   │
                                                     [再来一次] ──────────┘
```

### 2.2 核心玩法规则

| 规则项 | 具体值 |
|--------|--------|
| 开场倒计时 | 5 秒（5 → 4 → 3 → 2 → 1 → GO!） |
| 游戏总时长 | 60 秒（正式开始后倒计时） |
| 点中小球得分 | +1 / 次 |
| 点击空白区域 | -1 / 次，但得分最低为 0，不出现负数 |
| 同屏小球上限 | 最多 3 个同时存在（点中即释放位置，立刻补新球） |
| 新球生成时机 | 点中旧球 → 旧球消失动画 → 新球 **立即** 生成（无人为延迟） |
| 结束条件 | 60 秒倒计时归零 → 立即停止生成小球 → 锁定得分 |

### 2.3 功能点清单

#### F1. 开始按钮
- **位置**：页面居中，位于游戏区域正中央（初始状态）；倒计时阶段固定不动
- **样式**：圆角矩形按钮，白色字体，蓝色主色，阴影，hover 有轻微上浮和颜色加深
- **状态**：
  - `idle`：初始可见，按钮文字"开始游戏"
  - `counting`：开场倒计时阶段，按钮隐藏，数字覆盖在屏幕中央显示
  - `playing`：游戏进行中，按钮不可见
  - `ended`：游戏结束后，按钮文字变为"再来一次"，重新出现在中央
- **点击行为**：
  1. idle → 点击 → 进入 F2 开场倒计时
  2. 倒计时结束 → 进入 F3 游戏进行中
  3. 游戏结束 → 点击"再来一次" → 重置分数，重新走开场倒计时流程

#### F2. 开场倒计时动画
- **时长**：5 秒
- **视觉**：大字号数字从 `5` 逐帧变 `4`→`3`→`2`→`1`→`GO!`，每帧 1 秒
- **动画效果**：数字从上方 150% 位置下落至屏幕中央，伴随透明度从 0 → 1 → 0 的缩放弹跳动画（scale 0.5 → 1.2 → 1.0）
- **取消逻辑**：倒计时期间 ESC 键可取消，按钮回归 idle

#### F3. 小球生成与随机位置
- **尺寸**：固定直径 `60px`（适合触屏 & 桌面鼠标）
- **颜色**：实心蓝 `#2E86DE`，带 `box-shadow` 内发光 `inset 0 -4px 8px rgba(0,0,0,0.25)` 和外阴影 `0 4px 12px rgba(46,134,222,0.4)`
- **出现动画**：小球从 scale 0 淡入到 1.0，同时伴随 10px 下落位移动画，时长 300ms，使用 ease-out 曲线
- **随机位置边界**（`top / left` 计算范围）：
  - 上边界：分数栏底部 + 20px 留白（避开顶部 UI 区域）
  - 下边界：页面底部 - 小球直径 - 20px
  - 左边界：20px（避免贴边）
  - 右边界：页面宽度 - 小球直径 - 20px
- **多球间距**：新球生成时检测与现有球中心距离 ≥ 小球直径（60px），否则重新随机位置（最多重试 20 次，超过则放弃本次生成）
- **同屏上限**：任何时刻页面上小球 DOM 数量 ≤ 3；达到上限后停止生成，直到有球被点中

#### F4. 点击交互逻辑
- **点中小球**：
  1. 阻止事件冒泡（避免触发空白扣分）
  2. 得分 +1，触发分数栏数字动画（F5）
  3. 小球播放消失动画（放大 1.3 倍 + 透明度 0 + 轻微碎裂粒子效果，时长 250ms）
  4. 动画结束后移除该 DOM 元素
  5. **立即**生成一个新位置小球（同屏数量保持稳定）
  6. 在点击位置弹出 "+1" 飘字（向上飘 40px 后淡出，600ms）
- **点击空白区域**：
  1. 得分 -1，但限制在 [0, +∞)，不可扣负
  2. 分数栏数字变红闪烁一次（200ms 恢复）
  3. 在点击位置弹出 "-1" 飘字（红色，快速下坠 30px 后淡出，500ms）
  4. **不影响**小球位置与生成节奏
- **事件实现**：使用事件委托，在游戏容器上监听单次 `click`，判断 `event.target` 是否为小球元素

#### F5. 分数栏（顶部固定）
- **位置**：`position: fixed; top: 0; left: 0; width: 100%; z-index: 100`
- **布局**：左侧显示"⏱ 剩余时间"，中间大字号显示当前得分，右侧留空或放一个隐蔽的重置小图标
- **样式**：
  - 背景：白色半透明 `rgba(255,255,255,0.85)`，底部 1px 浅灰分割线
  - 高度：64px，内边距 0 24px
  - 字体：左侧时间用 16px 深灰，中间得分用 32px 加粗深蓝色 `#1B4F72`
- **实时更新动画**：
  - 得分变化时，数字整体向上位移 4px 后回到原位（200ms，ease-out）
  - 得分增加时数字微放大 1.1 倍再恢复；扣分时数字变红 200ms 恢复
  - 剩余时间每秒刷新；时间进入最后 10 秒时整体数字变为红色并轻微抖动
- **不被小球遮挡**：分数栏 `z-index: 100` > 小球 `z-index: 10`

#### F6. 游戏结束展示
- **触发**：60 秒倒计时归零
- **行为**：
  1. 立即停止小球生成；现有小球可保留或统一淡出（建议统一淡出 400ms）
  2. 分数栏停止更新
  3. 屏幕中央弹出结束遮罩层：半透明黑色 `rgba(0,0,0,0.6)` 覆盖整个视口
  4. 遮罩层内显示：
     - "游戏结束" 标题（白色，48px）
     - "本次得分：X 分"（白色大字，36px，加粗）
     - "再来一次" 按钮（蓝色主色，圆角，白色字体，点击重置进入开场倒计时）
- **Esc 关闭**：结束遮罩打开时按 Esc 可直接重置进入开场倒计时

#### F7. 分数重置逻辑
- **触发**：点击"再来一次"、结束遮罩按 Esc、或隐蔽重置图标点击
- **行为**：
  1. 得分重置为 0
  2. 清除所有现有小球 DOM
  3. 剩余时间重置为 60 秒
  4. 重新进入开场倒计时流程

## 4. 交互规则

### 4.1 动画时长表

| 动画 | 时长 | 曲线 |
|------|------|------|
| 开场倒计时数字弹跳 | 1000ms / 帧 | ease-out（下落）+ cubic-bezier（弹跳） |
| 小球出现动画 | 300ms | ease-out |
| 小球消失动画 | 250ms | ease-in |
| 得分飘字 | 600ms | ease-out（向上减速） |
| 扣分飘字 | 500ms | ease-in（向下加速） |
| 分数栏数字更新抖动 | 200ms | ease-out |
| 分数最后 10 秒红色抖动 | 每 500ms 一次 | linear 抖动 |
| 开始按钮 hover 上浮 | 150ms | ease-out |

### 4.2 事件处理优先级

1. 游戏容器 `click` 事件 → 判断点击目标
   - `event.target` 匹配 `.ball` → 小球点击处理（得分 +1 + 消失动画 + 生成新球）
   - 其他 → 空白区域处理（得分 -1，最低 0）
2. 开始按钮 `click` → 状态机切换至开场倒计时
3. 结束遮罩内"再来一次"按钮 `click` → 重置 + 重新开场倒计时
4. 全局 `keydown` → Esc 键快捷：倒计时中取消 / 结束时重置

### 4.3 响应式适配规则

| 断点 | 处理方式 |
|------|----------|
| ≥ 768px（桌面） | 基准值，保持小球 60px，按钮 160×52 |
| 480px – 767px（平板） | 小球缩至 50px，倒计时数字缩至 90px，布局不变 |
| < 480px（手机） | 小球缩至 44px，按钮缩至 140×44，竖屏优化，随机边界自动适配视口尺寸 |
| 触屏设备 | 不做额外修改，click 事件自动兼容（不使用 `touchstart` 以免双击问题） |

### 4.4 可访问性（A11y）最低要求
- 开始按钮加 `role="button"` + `aria-label="开始游戏"`
- 分数栏加分时朗读可通过 `aria-live="polite"` 更新文本内容（可选，不强制）
- 倒计时动画保留 `aria-hidden="true"` 避免屏幕阅读器重复朗读

## 5. 技术实现要求

### 5.1 技术栈约束
- **严格不引入任何第三方框架或库**（禁止 React / Vue / jQuery / lodash / 任何 CDN）
- 纯原生：HTML5 + CSS3 + 原生 JavaScript（ES6+ 语法）
- 不使用 Shadow DOM、Canvas（小球用 DOM 元素 + CSS 动画实现）

### 5.2 文件结构（模块化）

```
project-root/
├── index.html           # 入口，只放 HTML 骨架
├── css/
│   └── style.css        # 全部样式，含媒体查询
├── js/
│   └── main.js          # 全部逻辑，单一模块（课堂作业规模无需拆分多文件）
└── spec.md              # 本文件
```

> 说明：作业规模单一，JS 拆成多个文件反而增加复杂度，约定 **一个 main.js** 内按功能区用注释分段即可。

### 5.3 代码组织规范

```js
// === 常量区 ===
const CONFIG = { /* 颜色/尺寸/时长等 */ };

// === 状态区 ===
const state = { score, timeLeft, phase, ballsCount, ... };

// === DOM 引用 ===
const $ = { scoreEl, timeEl, container, ... };

// === 函数区 ===
function startCountdown() { ... }
function generateBall() { ... }
function handleClick() { ... }
function updateScore() { ... }
function endGame() { ... }

// === 初始化 ===
document.addEventListener('DOMContentLoaded', init);
```

### 5.4 性能要求

| 项 | 要求 | 说明 |
|----|------|------|
| 小球 DOM 数量 | 同屏最多 3 个 | 避免大量 DOM 节点 |
| 事件绑定 | 游戏容器上**事件委托** | 不每个球绑一次 |
| 动画实现 | 优先 CSS transition / animation | JS 只负责状态切换，避免 JS 动画 |
| 定时器 | 倒计时用 `setInterval`，小球生成按需触发（事件驱动） | 不做 60fps 轮询 |
| DOM 操作 | 批量集中更新（减少 reflow） | 分数栏更新先改 state，再一次改 DOM |
| 页面重绘 | 避免频繁改动 `width/height/top/left` | 小球位置用 transform 预设计算，直接赋给 left/top |

### 5.5 浏览器兼容性

| 浏览器 | 最低版本 | 特性 |
|--------|----------|------|
| Chrome / Edge | 100+ | ES6+、CSS transition/animation、backdrop-filter |
| Firefox | 100+ | 全部特性支持 |
| Safari | 15+ | backdrop-filter 可能降级，直接忽略 |
| 移动端（iOS Safari / Chrome Android） | 最新两版 | 触屏 click 兼容 |

## 6. 边界与异常处理

| 场景 | 处理方式 |
|------|----------|
| 浏览器窗口 resize | 游戏进行中 resize 时，现有小球位置保持不变；新生成小球按新边界计算（已在随机函数中每次实时计算，无需特殊处理） |
| 生成新球时空间不足（重试 20 次仍撞） | 放弃本次生成，等下一个点击触发 |
| 用户快速连点小球 | 每个小球 DOM 只响应一次点击，触发事件后立刻 `pointer-events: none` + 开始消失动画，避免重复得分 |
| 用户在倒计时中刷新页面 | 丢失进度（无 localStorage 持久化，简单游戏无需持久化） |
| 游戏进行中网络断开 | 无影响（全前端逻辑） |
| 页面可见性变化（切标签页） | `visibilitychange` 检测到隐藏时暂停定时器，恢复显示时按 `timeLeft` 继续倒计时（避免后台定时器被浏览器节流导致时间流逝异常） |
| DOM 节点过多或内存泄漏 | 游戏结束后清理所有小球 DOM + 清除所有 interval/timer |
| 用户点击分数栏区域 | 算作空白点击（分数栏背景不是小球，不触发小球逻辑）；可接受扣分 |
